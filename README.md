# 麦麦营养均衡助手（MCD Nutrition Balance）

> 麦当劳程序员创意开发大赛参赛作品 · 基于麦当劳官方 MCP 开发

## 这是什么

一个帮你**在下单前看清这一餐**的麦当劳点餐助手。

官方 App 会告诉你「有什么」、「多少钱」，
但不会告诉你「**这一餐的钠超了多少**」，更不会说「**怎么换更均衡**」。

本项目把麦当劳官方营养数据接到点餐决策链上，做两件事：

1. **套餐体检** —— 给出任意官方套餐的六维营养画像，逐项指出超标/不足
2. **替换处方** —— 在**官方允许的替换项范围内**求解最优组合，给出「换什么、能改善多少、要加多少钱」

> 与常见「营养推荐」类工具的区别：我们不做凭空拼餐（那样点不出来），
> 只在**官方真实可下单**的选项里做优化；当官方选项救不了时，**如实说明根因**。

## 目标用户

- 关注钠摄入、热量控制的上班族（麦当劳是高频午餐选择）
- 需要给家人（尤其长辈）点餐、但看不懂营养表的人
- 想「吃得明白」而不是「被推荐」的普通消费者

## 核心功能

### 1. 六维营养体检

以《中国居民膳食营养素参考摄入量（2023版）》与《中国居民膳食指南（2022）》为依据，
按餐次（早 25–30% / 午 30–40% / 晚 30–35%）换算每餐目标，覆盖 6 个维度：

| 维度 | 说明 |
|---|---|
| 能量 | kcal |
| 蛋白质 | g（按「每餐 20–30g」均匀分配原则，不按能量比例缩放） |
| 脂肪 | g（按 20–30% 供能比换算） |
| 碳水化合物 | g（按 50–65% 供能比换算） |
| 钠 | mg（全天上限 2000mg 按餐次分配） |
| 钙 | mg（全天推荐 800mg） |

### 2. 替换处方（本项目的核心差异化）

麦当劳套餐的每一轮（主食 / 小食 / 饮料）都提供官方替换项。
本项目穷尽全部替换组合（如巨无霸三件套为 5×16 = 80 种），
按营养均衡度评分，输出最优的 3 个方案，并标注**官方差价**。

### 3. 根因兜底

当穷尽官方替换项后仍无法达标（实测：**三个主流套餐的钠均无法救回**），
明确指出「根因在主食」，并给出根本解法建议。

> 营养表未收录的可选项会被**自动隐藏**（界面会说明隐藏数量），保证任一可选组合都能算出营养结果。

## 一个反直觉的发现

按各套餐的**默认组合**做体检，得分最高的并不是最贵的：

| 套餐 | 价格 | 得分 | 钠 |
|---|---:|---:|---:|
| 吉士汉堡包套餐 | ¥26.5 | **85.5** | 492 mg |
| 麦香鱼套餐 | ¥33 | **84.3** | 556 mg |
| 巨无霸三件套 | ¥37.5 | 70.0 | 961 mg |
| 麦辣鸡腿汉堡三件套 | ¥33.5 | 70.6 | 1208 mg |

原因在于钠：招牌汉堡的钠普遍偏高，而吉士汉堡包、麦香鱼属于"清淡派"。
**贵买的是分量与口味，不是营养均衡。**

## 网页演示台

不方便安装环境？直接打开网页版即可体验全部逻辑：

- **在线体验**：https://icarus-alpha-1264.github.io/nutrition-assistant/
- **本地打开**：双击 `docs/index.html`（**单文件、零依赖、无需联网、无需 Token**）

网页支持**交互式对比**：切换套餐、小食、饮料，六维营养条与评分实时变化，
并自动列出「官方允许范围内的最优替换方案」。

> 网页与 Skill 的分工：
> **网页**负责"让人 10 秒看懂"（内置数据快照，供路人体验）；
> **Skill**负责"真实可用"（通过 WorkBuddy + 麦当劳 MCP 实时取数）。
> 网页不包含任何 Token，也不直接调用 MCP。

网页由脚本生成，改动数据后重新生成即可：

```bash
python scripts/build_web.py
```

## 使用示例

### 示例：巨无霸三件套 ¥37.5（男性 2250 kcal/天）

**默认组合**：巨无霸 + 中薯条 + 可乐中杯

```
能量 949kcal | 蛋白 31g | 脂肪 38g | 碳水 116g | 钠 1126mg | 钙 199mg
体检结论：能量超5%、脂肪超27%、钠超66%、钙低8%   ｜ 得分 70.0/100
钠来源：主食 961 + 小食 165 + 饮料 0 = 1126mg（上限 680mg）
```

**处方输出**：

```
1) 中薯条 → 大杯玉米杯 ｜ 可乐中杯 → 可乐大杯
   能量 824kcal | 蛋白 31g | 脂肪 27g | 碳水 109g | 钠 963mg | 钙 196mg
   得分 83.0（+13.0）｜ 差价 +¥3.5

2) 中薯条 → 小杯玉米杯 ｜ 可乐中杯 → 可乐大杯
   能量 790kcal | 蛋白 29g | 脂肪 27g | 碳水 104g | 钠 962mg | 钙 192mg
   得分 82.5（+12.5）｜ 差价 +¥1.0

⚠ 穷尽官方全部替换项后，钠仍无法达标（理论最低 962mg，上限 680mg）
  根因：主食「巨无霸」自身含钠 961mg，占了大头。
  要真正解决，只能更换主食（如麦香鱼 556mg、吉士汉堡包 492mg）。
```

## 安装方法

### 前置条件

- 已申请麦当劳中国 MCP Token：https://open.mcd.cn/mcp
- Python 3.10+（本项目仅使用标准库，无第三方依赖）
- 支持 MCP 的客户端（推荐 [WorkBuddy](https://www.workbuddy.cn/)）

### 步骤 1：配置 MCP 连接

参考 `mcp-config.example.json`，把 `${MCD_MCP_TOKEN}` 替换为你的真实 Token：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

在 WorkBuddy 中：左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，粘贴上述 JSON 并保存、启用。

### 步骤 2：运行

```bash
# 套餐体检 + 替换处方
python scripts/combo_doctor.py male     # 男性基准（2250 kcal/天）
python scripts/combo_doctor.py female   # 女性基准（1800 kcal/天）

# 早餐营养均衡组合搜索
python scripts/breakfast.py
```
