## ⚠️ 提交前必看（官方自动校验较严格）

| 要求 | 说明 |
|---|---|
| **不要换行** | 标题和正文之间不要有多余空行；`【参赛申请】`、`项目名称：`、`项目地址：`、`项目简介：` 各项之间也不要换行 |
| **不要用 Markdown 链接** | 项目地址直接贴纯文本 URL，不要写成 `[xxx](https://...)` 形式 |
| **仓库必须公开** | Public 仓库，未登录也能访问 |
| **仓库创建时间** | 需在 2025-12-25 – 2026-10-25 之间（你现在创建没问题） |

## 提交后

- ❌ 报名失败 → 回复里会写明原因，修改后可重新提交
